Every linear gradient in the file drifts along its own axis while the shapes stay put. Works with Figma exports, including this tool's own SVGs. Radial gradients stay still.

Structure

Click a column in the artwork to split it in two. Hold ⇧ while clicking, or switch to Merge, to join it back. Rebuild resets manual edits.

Gradient

Per-column variation

Shift moves the gradient along its axis per column; Length stretches it so the middle colours take over. Use Click does → Tune to set one column by hand.

Finish

Soften lays a blurred copy over the sharp artwork; Mix is that copy's opacity. PNG always matches the preview. Figma imports the blur as a layer blur when it can.

Motion

Only the gradients drift; the shapes stay put. Still shows the exact frame you export. The SVG carries the motion for browsers; PNG and Figma take the still frame. Shuffle or Randomise re-rolls which gradient drifts first.

Export

Drop the SVG file onto a Figma canvas, or paste the copied SVG code: every column arrives as its own editable gradient fill. The MP4 renders one full drift cycle at 30 fps, so it loops seamlessly, using the Motion drift and speed whether or not the preview is moving.
